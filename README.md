# Pizza-Sales-Analysis
# 🍕 Pizza Sales Performance Report | SQL & Power BI

## 1. Project Title / Headline

### 🍕 Pizza Sales Performance Report | SQL & Power BI

An end-to-end Sales Analytics project built using **SQL** and **Power BI** to analyze restaurant sales performance, customer ordering patterns, product popularity, and revenue trends. The dashboard transforms raw sales data into meaningful business insights, enabling restaurant managers to make informed decisions that improve sales, optimize inventory, and enhance customer satisfaction.

---

## 2. Short Description / Purpose

The Pizza Sales Performance Report is an interactive business intelligence dashboard developed using **SQL** and **Power BI**. The project analyzes one year of pizza sales data to uncover valuable insights into revenue, customer purchasing behavior, product performance, and sales trends.

The dashboard enables restaurant owners, managers, and business analysts to monitor key performance indicators (KPIs), identify top-selling products, understand customer preferences, and support strategic business decisions through interactive visualizations.

---

## 3. Tech Stack

The project was built using the following tools and technologies:

- 🗄️ **SQL (MySQL)** – Used to query the database, extract business insights, calculate KPIs, and perform sales analysis.
- 📊 **Power BI Desktop** – Used to create interactive dashboards and visualize sales performance.
- 📂 **Power Query** – Used for data cleaning, transformation, and loading (ETL process).
- 🧠 **DAX (Data Analysis Expressions)** – Used to create calculated measures, KPIs, and dynamic calculations.
- 📝 **Data Modeling** – Built relationships between Orders, Pizza, Pizza Types, and Category tables to enable accurate reporting.
- 📈 **Data Visualization** – Used various charts including KPI Cards, Line Charts, Donut Charts, Treemaps, Area Charts, and Stacked Column Charts.
- 📁 **File Formats**
  - `.sql` – SQL Queries
  - `.pbix` – Power BI Dashboard
  - `.csv/.xlsx` – Dataset
  - `.png` – Dashboard Preview

## 4. Data Source

**Source:** Pizza Sales Dataset

The dataset contains one year of pizza sales transactions from a restaurant business.

The dataset includes:

- Order ID
- Order Date & Time
- Pizza Name
- Pizza Category
- Pizza Size
- Quantity Sold
- Unit Price
- Total Sales Amount

SQL was used to query and analyze the raw sales data before importing it into Power BI for dashboard development.

## 5. Features / Highlights

### • Business Problem

Restaurant businesses generate thousands of sales transactions every year. However, identifying best-selling pizzas, customer preferences, revenue trends, and sales performance from raw transactional data is challenging.

Business stakeholders need answers to questions such as:

- Which pizzas generate the highest revenue?
- Which pizzas are ordered most frequently?
- Which pizza category contributes the most sales?
- Which pizza size is preferred by customers?
- Which months generate the highest revenue?
- Which days of the week receive the highest number of orders?
- Which products require promotional efforts to improve sales?

Without proper analytics, answering these questions is time-consuming and limits effective decision-making.

---

### • Goal of the Dashboard

The dashboard was developed to:

- Monitor overall restaurant sales performance.
- Analyze customer ordering behavior.
- Identify top-performing and low-performing pizzas.
- Compare sales across pizza categories and sizes.
- Track monthly revenue trends.
- Support inventory planning and menu optimization.
- Enable restaurant managers to make data-driven business decisions.
